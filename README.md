# RoomDatabase — Employee Manager

A hands-on Android project built to understand **Room Database** and how local persistence works in Android applications.

This project explores how structured data can be stored, retrieved, updated, and deleted using Room, with a Jetpack Compose interface for interacting with employee records.

## 📱 Application Preview

The application provides an Employee Manager screen where users can enter employee details and manage saved records.

## ✨ Features

- **Add employees** — Save employee names and ages.
- **View employees** — Display saved employee records in a list.
- **Update employees** — Modify an existing record using its employee ID.
- **Delete employees** — Remove records from the database.
- **Local data persistence** — Use Room to manage structured local data.
- **Jetpack Compose UI** — Build the interface using declarative UI components.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Database:** Room Persistence Library
- **IDE:** Android Studio
- **Build system:** Gradle with Kotlin DSL

## 🚀 Getting Started

### Prerequisites

- Android Studio
- A compatible Android SDK
- Basic familiarity with Kotlin

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/sukhpreetsingh04/RoomDatabase.git
   ```

2. Open the project in Android Studio.
3. Allow Gradle to sync and resolve dependencies.
4. Run the application on an Android emulator or a compatible physical device.
